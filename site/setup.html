Setup guide

From ZIP to road trip.

The Swift project and this static site live together, so the repo can host its marketing pages on GitHub Pages or Cloudflare Pages while Xcode owns the native app.

1. Open the app

Open MuseCarPlay.xcodeproj in Xcode, choose your team and bundle identifier, then add the CarPlay capability under Signing & Capabilities.

2. Wire Muse chat

Replace the placeholder response in MuseCarPlay/Chat/MuseChatService.swift with your authenticated Muse API request. Keep credentials out of the static site.

3. Publish the HTML

Set the hosting directory to site/. Both GitHub Pages and Cloudflare Pages serve the relative links in this folder without a rewrite framework.

site/ ├── index.html ├── features.html ├── setup.html ├── about.html ├── 404.html ├── favicon.svg └── assets/

4. Review before launch

  • Request the correct Apple CarPlay entitlement.
  • Test speech permission denial and audio interruptions.
  • Keep driving interactions short and glanceable.
  • Confirm every public page works under your project subpath.
