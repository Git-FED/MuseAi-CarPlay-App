Project notes

Not another tiny WebView.

MuseCarPlay is a native CarPlay starter with a clear separation between dashboard UI, voice services, chat integration, and places data.

Why native?

CarPlay apps use Apple's templates and interaction rules. That makes this scaffold easier to reason about on the road and gives the app a proper entitlement path instead of treating the dashboard like a miniature browser.

Where the pieces live

  • CarPlay/ contains native templates.
  • Voice/ contains speech recognition, synthesis, and session coordination.
  • Chat/MuseChatService.swift is the Muse integration seam.
  • Places/ and Models/ hold the replaceable data layer.
  • site/ is a static marketing and documentation site for GitHub Pages or Cloudflare Pages.
